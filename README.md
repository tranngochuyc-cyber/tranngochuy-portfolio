# HUY.STUDIO — Portfolio Trần Ngọc Huy

Portfolio Web & Motion Studio, chủ đề đại dương sâu: “lặn từ 0 m đến 11.000 m”.

- Một trang `index.html` thuần (HTML + CSS + JS), dùng GSAP + ScrollTrigger và Lenis qua CDN
- Tôn trọng `prefers-reduced-motion`, có bản mobile nhẹ
- Font: Unbounded + Be Vietnam Pro

## Chạy thử
Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages (Settings → Pages → Deploy from branch `main`).

Xem `brief.md` để biết phần cần thay và kế hoạch chuyển sang full-stack (Next.js + Supabase).
